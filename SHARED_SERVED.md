# Shared Hoilday server

The app's accounts, public calendar, seasonal ranks, online list, and community chat messages are stored by `server.py` in a SQLite database at `~/.dayglow.sqlite3`. This is one shared database for everyone using the same running Codespace.

Hoilday opens to an iPad-style app home screen. The **Auto Clicker** app configures a floating clicker available on Hoilday pages; set its interval, click count, and start/stop hotkey, then press the hotkey while the pointer is over a target. It is limited to 100,000 clicks per run and does not operate on other sites or apps. The **Thanksgiving Feast** app appears November 23–26, 2026 (America/New_York) and closes at midnight on November 27. Before the kitchen opens, it shows a live countdown to 4:00 PM on November 23. Sign in and complete 24 ordered prep, seasoning, and cooking steps across eight dishes; progress saves per account. Finishing the feast grants a Thanksgiving text color decorated with a turkey above each letter, the Harvest Feast profile ring, Turkey and Pumpkin emojis, 75 Candy Canes, 10 Gummy Bears, 5 Gingerbread people, and 25 regular fish. The server grants the feast rewards once per account. The **Christmas** app keeps its glowing screen and countdowns to Christmas Day and the Advent Calendar update. The separate **Advent Calendar** app appears December 1–25, 2026; claiming its daily rewards reveals **Holiday fishing**, **Holiday shop**, **Text Color Fishing**, and **Christmas Tree** as separate apps on their scheduled unlock days. Rufus can preview the reward descriptions in gold-framed cards in the Admin panel; the preview cannot grant rewards. The **Gifts & trades** app lets signed-in members choose recipients from a member dropdown, send an unlocked rank, emoji, or profile ring, or make a one-for-one trade offer. Trade choices reflect the selected recipient's current collection; stale or unavailable items are rejected by the server. Member trade offers can be accepted, declined, or cancelled. A member cannot give away their last rank, and each accepted trade moves both items together.

The **Export / import** app downloads an account backup containing its username, rank and fish progress, unlocked ranks, emojis and profile rings, equipped profile ring, completed side quests, and profile picture. Passwords are never exported. Import creates a separate account when the backed-up username is available; to restore into an existing account, sign in to that same username first. This replaces that account's saved progress but keeps its current password. Other existing accounts cannot be overwritten. The **Updates** app shows the current release and previous release notes.

Start the app server from the Codespaces terminal:

```sh
python3 server.py
```

Run the API regression tests with:

```sh
npm test
```

Open port 4173 in the Codespaces **Ports** tab, set its visibility to **Public** if you want to share it outside your GitHub account, then share its HTTPS forwarded link. Anyone using the link can view public calendar events; each person creates their own username and password to edit the calendar, fish, and join the shared chat. Chat history is visible to signed-in members. The Codespace needs to be running for the app to be available. The database file remains in the Codespace home folder when the server stops.

While signed in, the app checks for new chat messages and shows an alert for each incoming message. Automatic chat moderation bans an account for 5 minutes for a message containing a word longer than 10 characters, 7 or more identical characters in a row, or common English profanity (slurs are not included in the filter). The user is signed out and shown a notice explaining the ban. Browser notifications require each person to grant permission with **Enable chat notifications** in the chat page; a website cannot grant permission automatically. The **Clear history** button deletes messages for everyone after confirmation. New app releases are detected from a build fingerprint and refresh automatically when no editor is open and no chat draft is being written. The release title and description are shown after refresh; update `package.json` under `hoilday.update` with the release notes.

Fishing unlocks ranks for an account's collection without changing the selected profile rank. Snowball is a Legendary rank with a 0.01% catch chance; Cameron has a 0.2% catch chance and Holiday 0.1%. The 5% Fall and 2% Turkey catches switch to Gingerbread and Reindeer each November 27 (UTC). The old Fall and Turkey ranks remain in collections and can still be equipped. Side quests award Harvest and Drumstick until the switch, then Elf and Snowman; already-earned rewards remain saved.

The Emojis tab has a separate emoji-fishing action: Pumpkin (49.9%), Snowflake (30%), Ice Cube (15%), Christmas Tree (5%), or Legendary Reindeer (0.1%). Regular fishing unlocks Turkey at 500 catches before November 27, then Christmas Tree at 500 catches; Present unlocks at 1,000 catches. Previously unlocked emojis remain in the account collection and can still be equipped.

The ring-fishing app awards profile rings with each cast: White (49.975%), Red (30%), Peppermint (14%), Gold (3%), Santa (2%), Cookie (0.075%), Christmas (0.1%), and Candy cane (0.25%). Turkey (0.6%) is catchable before November 27; the decorated Present ring (0.6%) replaces it from November 27 through December 31 (UTC). Retired rings stay in collections and can still be equipped or traded. Equipped rings are backfilled into older accounts' collections so they remain tradable.

Signed-in members can upload a JPEG, PNG, or WebP profile picture from the Profile tab. The browser crops and compresses the image to a square JPEG (maximum 256 KB); it appears beside the username in chat and the online list. Pictures are stored with the shared account database and can be removed from the Profile tab.

The `rufus` account has an Admin panel below Emojis. It can view profiles of online members, send them personal warning pop-ups, ban them for 5 minutes, 1 hour, 1 day, 1 week, 30 days, 90 days, or 1 year, and unban active bans. A ban signs the account out immediately and blocks sign-in until the ban expires or is removed; the Admin panel shows the ban reason. The admin can toggle global Winter mode (white with black text and falling snowflakes), Camel Weather (camel orange with white text and large spinning camel emojis raining across the screen), or Christmas Weather (a festive red-and-green theme with falling Christmas tree emojis). These global modes include visitors and offline members; only one can be active at a time, and turning it off restores each person's locally saved theme. Rufus can grant or remove member ranks, emojis, rings, Holiday collectibles, and Holiday currencies; publish or clear a global announcement; and create, edit, or delete public calendar events. The Accounts tab can permanently delete a non-admin account after confirmation; its sessions, progress, and chat messages are removed, and its report author name is anonymized. Signed-in members other than Rufus can send a private report from the Report page; Rufus can review reports and mark them as read in the Admin panel's Mail tab. The `rufus` username can be claimed through public sign-up, and whoever registers it receives the admin permissions. If sharing the server publicly, register `rufus` yourself before sharing the link.


Usernames are 3–20 letters, numbers, or underscores. Passwords must be at least 8 characters. Passwords are stored as salted, slow hashes. There is no password reset yet, so choose a password you can remember. Do not delete `~/.dayglow.sqlite3`, or the accounts and calendar will be lost.
